# Image Classification Using TensorFlow

A TensorFlow model that classifies handwritten digits from the MNIST dataset. The notebook walks through loading the data, building and training a neural network, evaluating accuracy, and visualizing predictions.

## Tech Used

- Python
- TensorFlow / Keras
- NumPy
- Matplotlib

## Project Structure

```
Basic Image Classification using Tensorflow.ipynb   # Main notebook
```

## How to Run

1. Install dependencies:
   ```bash
   pip install tensorflow numpy matplotlib
   ```
2. Open the notebook:
   ```bash
   jupyter notebook "Basic Image Classification using Tensorflow.ipynb"
   ```
3. Run all cells to train the model and see the results.
